# 🖥️ Operating Systems Lab

This repository contains a collection of **Operating Systems Lab experiments and practical implementations** covering fundamental OS concepts using **Bash Shell Scripting, Linux commands, and C programming**.

## 📚 Topics Covered

- 🐧 **Basic Linux Commands:** Bash commands, I/O redirection, pipes, and file/directory operations.
- 📂 **File Management:** File searching, handling, text manipulation, and Vi/Nano editors.
- ⚙️ **Process Management:** Process monitoring, creation, child processes, and PID management.
- 💻 **Linux Utilities:** Practical use of `date`, `who`, `sed`, `free`, `top`, `pmap`, and `time`.
- 📝 **Shell Scripting:** File handling, string operations, and user/process information.
- 🔤 **String Operations:** String manipulation using Bash scripts and C programming.
- 🧠 **Memory Management:** Memory allocation, memory usage analysis, and virtual memory concepts.
- 🚀 **Process Analysis:** CPU-bound and I/O-bound process analysis.
- 🔍 **Memory Mapping:** Understanding process memory maps and observing virtual memory addresses.

## 🛠️ Languages & Tools

- C Programming
- Bash Shell Scripting
- Linux / Ubuntu
- GCC Compiler
- Terminal & Linux Utilities

## 🎯 Objective

To gain practical knowledge of Operating System concepts, understand Linux-based system operations, and develop hands-on programming and scripting skills.
